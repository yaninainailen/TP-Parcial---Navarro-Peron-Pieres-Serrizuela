# Agente de respuestas a clientes

## Qué construí

Un agente que responde consultas de clientes de una tienda de ropa.

## Cómo se lo pedí

Le pedí que clasifique los mensajes de los clientes y conteste. El prompt está en
`prompts/system_prompt.md`.

## Qué funciona

Anda bien, contesta los mensajes que le paso. Ver `corridas/`.

## Qué falta o qué falló

Por ahí a veces contesta distinto de otras veces pero en general funciona.

## Qué aprendí

Aprendí a usar prompts para automatizar respuestas. El modelo no es caro así que se puede usar
tranquilamente para esto.
