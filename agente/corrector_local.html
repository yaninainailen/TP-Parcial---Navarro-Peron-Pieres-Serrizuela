Preparar corrección del agente evaluador

Pegá la URL de un repo público de GitHub. La página busca el repo (gratis, sin key ni login) y arma el prompt completo con agente/system_prompt.md + rubrica.md + el contenido real del repositorio. Con eso podés: (a) apretar "Evaluar con Claude" para que la página llame directo a la API de Anthropic y muestre la corrección junto con el uso de tokens de esa corrida, o (b) apretar "Preparar prompt" para copiarlo a mano y pegarlo en cualquier chat de IA. La opción (a) necesita tu propia API key de Anthropic y consume crédito pago de tu cuenta — la (b) es gratis.

La key se guarda solo en el navegador (localStorage), nunca se sube al repo ni pasa por otro servidor — el pedido va directo de este navegador a api.anthropic.com. Igual, no es un lugar seguro para una key de producción: cualquiera con acceso a este navegador puede leerla. Precios de referencia, pueden cambiar — confirmá en la consola de Anthropic.
Si la API devuelve el error anthropic-workspace-id is required when authenticating with an identity-linked API key, tu key es personal y tiene acceso a varios workspaces: buscá el ID del workspace en Console → Settings → Workspaces (empieza con wrkspc_) y pegalo en el campo de arriba.
